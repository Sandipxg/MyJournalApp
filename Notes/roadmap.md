# React Roadmap

## 1. Prerequisites
- HTML
- CSS
- JavaScript (ES6+)
  - Variables, Functions, Arrays, Objects
  - Destructuring, Spread Operator
  - Array Methods (`map`, `filter`, `reduce`)
  - Promises, Async/Await
  - Modules (`import/export`)

---

## 2. React Fundamentals
- JSX
- Components
- Props
- State
- Event Handling
- Conditional Rendering
- Rendering Lists
- Forms & Controlled Components

---

## 3. React Hooks
- useState
- useEffect
- useRef
- useReducer
- useContext
- Custom Hooks ← not advanced, belongs here

---

## 4. Component Communication
- Props Drilling
- Lifting State Up
- Context API (with Provider pattern)

---

## 5. Routing
- React Router basics
- Dynamic Routes
- Route Parameters
- Nested Routes
- Protected Routes

---

## 6. Styling
- CSS / Inline Styles
- CSS Modules
- Tailwind CSS ← learn this, skip Sass/Emotion/Styled Components for now
- Styled Components (optional, later)

---

## 7. Forms
- Controlled Forms
- Form Validation
- React Hook Form ← skip Formik, RHF is the standard now

---

## 8. API Handling
- fetch API
- Axios
- Loading & Error States
- Async State Handling

---

## 9. State Management
- Context API + useReducer (built-in, learn first)
- Zustand ← pick this for external, simple and widely used
- Redux Toolkit ← only if working on large team projects

---

## 10. Advanced React
- Higher Order Components (HOC)
- Render Props
- Compound Components
- Portals
- Error Boundaries

---

## 11. Performance Optimization
- React.memo
- useMemo
- useCallback
- Lazy Loading & Code Splitting

---

## 12. TypeScript with React
- Start this as soon as you're comfortable with React
- Don't wait until the end

---

## 13. Testing
- Jest
- React Testing Library
- Unit & Component Testing

---

## 14. Server State Management
- TanStack Query (React Query) ← replaces manual fetch logic
- SWR (alternative)

---

## 15. Authentication & Security
- JWT Authentication
- OAuth
- Protected Routes
- Secure Token Storage

---

## 16. React Ecosystem
- Next.js ← most important framework to learn
- Remix (optional)
- Vite (already using), Webpack (good to know)

## 17. Real-world Development
- Folder Structure
- Reusable Components
- API Services Layer
- Environment Variables
- Deployment (Vercel / Netlify)
