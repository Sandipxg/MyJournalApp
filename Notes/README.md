## 🎯 How to Use These Notes

### 1. Start with Fundamentals
Begin with `01-fundamentals/` folder. Master these before moving forward:
- JSX syntax
- Components & Props
- State & Events
- Lists & Conditionals

### 2. Learn Hooks
Move to `02-hooks/` and learn in this order:
- useState & useEffect (most important)
- useRef & useReducer
- useContext
- Custom Hooks

### 3. Build Features
Apply your knowledge:
- Routing (React Router)
- Styling (CSS Modules or Tailwind)
- Forms (React Hook Form)
- API calls (fetch)

### 4. Advanced Patterns
- State management with Context + useReducer
- Performance optimization
- Testing

## 💡 Learning Tips

**Do:**
- Read one topic at a time
- Write code along with examples
- Build small projects to practice
- Refer back to notes when stuck

**Don't:**
- Skip fundamentals
- Try to learn everything at once
- Copy-paste without understanding
- Get discouraged by errors (they're part of learning!)
