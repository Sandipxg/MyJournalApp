# React Learning Guide - Getting Started

## Welcome! 👋

This is your comprehensive React learning resource. These notes are organized to take you from fundamentals to advanced concepts.

## How to Use These Notes

1. **Follow the numbered folders** - They're organized in learning order
2. **Practice as you learn** - Build small examples for each concept
3. **Refer back often** - These notes are reference material
4. **Track your progress** - Use `todo.md` to mark completed topics

---

## Learning Path

### Phase 1: Fundamentals (Weeks 1-2)
- JSX syntax
- Components & Props
- State & Events
- Lists & Conditionals

### Phase 2: Hooks (Weeks 3-4)
- useState & useEffect
- useRef & useReducer
- useContext
- Custom Hooks

### Phase 3: Routing & Styling (Week 5)
- React Router
- CSS Modules
- Tailwind CSS

### Phase 4: Forms & Data (Week 6)
- React Hook Form
- API calls with fetch
- Loading & error states

### Phase 5: State Management (Week 7-8)
- Context API + useReducer
- Advanced patterns

## Quick Tips

✅ **Do:**
